Файлы:

ВАЖНО: в исходных материалах не было ваших реальных ссылок.
В index.html замените href="#" у:
1) telegram↗
2) «написать мне» на первом экране
3) «написать мне↗» внизу

Например:
Telegram: href="https://t.me/username"
Почта: href="mailto:name@example.com"

Шрифт в CSS указан как Arial Narrow. Если на устройстве Arial Narrow не установлен,
браузер использует Arial как резервный вариант.
